# تدقيق التعريب — Checkpoint 06.2

`src/app/i18n.ts` يضبط `keySeparator: false` حتى تعمل مفاتيح مثل `errors.INVOICE_LOCKED`.

أزواج أُضيفت أو اُستخدمت للعرض دون تغيير القيمة المخزنة:

- الكيانات: `CUSTOMER` عميل، `EXPORT_CASE` عملية تصدير، `INVOICE` فاتورة، `BOOKING` حجز، `CONTAINER` حاوية.
- الأنواع: `TEXT` نص، وبقية الأنواع في `fieldType.*`.
- التذكير: `BEFORE` / `AFTER` و`DAYS` / `HOURS` عبر `offset.*` و`unit.*`.
- الصلاحيات: عنوان بشري في `perm.*` والمفتاح في واجهة البرمجة ثابت.
- الملف: `chooseFile` = اختيار ملف، والمدخل الأصلي مخفي بصريًا.
- قفل الفاتورة: `invoiceLockedTitle` = فاتورة مقفلة.
- تعارض الإصدار: `errors.INVOICE_VERSION`.

قائمة الحقول المحفوظة في الإعدادات لم تعد تعرض `CUSTOMER.field` و`TEXT` كنص أساسي؛ تعرض اسم الكيان والنوع المترجمين والمفتاح كما أُدخل.

لم يُفحص كل سطر ظاهر في المتصفح بعد التحميل في هذه المتابعة. أي مفتاح بلا ترجمة يظهر للمستخدم كنص احتياطي إن مرّ عبر `tx`، أو كما هو إن طُبع مباشرة. التقرير النهائي لا يدّعي صفر تسريب قبل لقطات ما بعد التحميل.
