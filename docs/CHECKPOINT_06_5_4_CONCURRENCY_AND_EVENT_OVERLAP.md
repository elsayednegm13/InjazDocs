# التزامن وتداخل الأحداث — Checkpoint 06.5.4

## السياسة

`reminder_rule_definitions` بلا عمود إصدار. الحفظ يطلب `expected` يطابق الأعمدة الحالية: التفعيل، المقدار، الاتجاه، الوحدة، التكرار، السقف. الاختلاف يعيد 409 `REMINDER_STALE` قبل الكتابة. داخل الدفعة عبارة `SELECT CASE ... ELSE 1/0` حتى تُرفض الدفعة إذا تغيّر الصف بين القراءة والتثبيت. لا ترحيل.

الواجهة ترسل اللقطة التي حمّلتها. عند الفشل تعرض رسالة الخطأ وتعيد قراءة القواعد ولا تعيد PATCH.
