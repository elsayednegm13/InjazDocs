## 24. مسار PATCH وعدد الرحلات

`PATCH /api/v1/reminder-rules/:id` → صلاحية `reminders.manage_rules` → `UPDATE reminder_rule_definitions` (يلتزم قبل إعادة الحساب) → تحميل صفوف العائلة في استعلام أو استعلامين → دفعات `db.batch` من 80 عبارة → تحديث `next_action` بعبارة واحدة.
