# ExportFlow — حزمة تنفيذ تصميم Premium Operations Workspace

## مكونات الحزمة

- `EXECUTION_PROMPT_CHECKPOINT_06_7_1.md`: برومت التنفيذ المتكامل بالإنجليزية، والتقرير النهائي المطلوب بالعربية.
- `REFERENCES/TARGET_01_Premium_Dashboard_AR.png`: تصميم لوحة العمليات الجديدة (مرجع بصري مولّد، وليس بيانات عمل حقيقية).
- `REFERENCES/TARGET_02_Premium_Export_Operations_AR.png`: تصميم قائمة عمليات التصدير مع لوحة عرض تفاصيل (مرجع بصري مولّد، وليس ميزة مطلوبة إذا كان API لا يدعمها).
- `BASELINE_CHECKPOINT_06_7/after/`: أربع وعشرون لقطة مرجعية من الواجهة السابقة لمقارنة التطوير.
- `SHA256_MANIFEST.txt`: بصمات الملفات للتأكد من أن المراجع لم تتبدل.

## طريقة الاستخدام مع Cursor أو وكيل برمجي

1. احتفظ بنسخة الحزمة الأصلية للرجوع إليها.
2. استخرج مجلد الحزمة بالكامل، مع الحفاظ على هيكل المجلدات، داخل مشروع ExportFlow المحلي، في مجلد توثيق مثل:
   `I:\WORK\InjazDocs\docs\design-references\ExportFlow_Premium_Workspace_Bundle\`
   **هذا المسار مثال؛ تحقق من جذر المشروع أولًا. لا تستخرج فوق ملفات موجودة.**
3. افتح `EXECUTION_PROMPT_CHECKPOINT_06_7_1.md` وأعطه للوكيل، مع توجيهه إلى الصور الحقيقية داخل `REFERENCES/`، وليس مجرد وصف نصي لها.
4. اطلب من الوكيل أولًا قراءة الصور واستخراج Mapping من كل منطقة في الموكاب إلى مكون ومصدر بيانات حقيقي، ثم التنفيذ وفق الضوابط.
5. لا توافق على بدء 06.8 أو أي نشر أو ترحيل أو تغيير Backend دون قرار منفصل.
