## 07. الأمن

- bootstrap مرة واحدة: طلبان متوازيان، نجاح واحد. سر ناقص: 403.
- لا تسجيل عام: `POST /api/auth/sign-up/email` ليس نجاحًا.
- آخر مدير: تعطيل النفس يعيد 409.
- دور مخصص: الواجهة تخفي Bookings وUsers، والـ API يعيد 403.
- البنك: آخر 4 أرقام فقط في الواجهة، والـ CSV بلا IBAN.
- الملف: تنزيل مصرح يبدأ بـ `%PDF`، وطلب بلا كوكي 401.
- الرابط العام: لا مبلغ ولا بنك، وتدوير يلغي القديم فورًا، و`Referrer-Policy: no-referrer` و`Cache-Control: no-store`.
- الحد العام للرابط في D1 مشترك بين عزلات نفس القاعدة المحلية، وليس حماية عالمية على حافة Cloudflare. ذلك يبقى قرار WAF للمالك.
- كرون التذكير: `notification_deliveries` بقيد فريد. اختبار التكرار الكامل تحت عزلين لم يُعاد هنا؛ اختبار الوحدة والمنطق موجودان.

## 08. سير العمل
