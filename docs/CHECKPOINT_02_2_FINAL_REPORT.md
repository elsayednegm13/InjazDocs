## 04. أخطاء مقروءة

العقد: `{ error: { code, message, fieldErrors?, requestId } }`. لا تُعاد تفاصيل SQL ولا المكدس.

- النوع الفارغ: 422 `DOCUMENT_TYPE_REQUIRED` + رسالة حقل عربية/إنجليزية (T01، E2E-06)
- الوزن القائم أقل من الصافي: `GROSS_LT_NET` (E2E-05)
- انتقال بنك غير قانوني: 409 `BANK_TRANSITION_NOT_ALLOWED` دون كشف from/to
- صلاحية ناقصة: 403 بلا معرّف صلاحية
- رابط متابعة باطل: 410 بلغة محايدة (T05، E2E-12)
- آخر مدير: 409 `LAST_ADMIN`
- فشل غير متوقع: 500 `SERVER_TEMPORARILY_UNAVAILABLE` (`tests/errors.test.ts`)
- تسجيل الدخول الخاطئ: «تعذر تسجيل الدخول» / Sign-in failed دون JSON أو رمز حالة

المصفوفة: `docs/CHECKPOINT_02_2_ERROR_MATRIX.md`.
