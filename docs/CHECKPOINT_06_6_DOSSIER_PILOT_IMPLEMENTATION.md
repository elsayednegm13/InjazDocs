# تنفيذ ملف العملية — Checkpoint 06.6

المسار: `/export-cases/:id` في `CaseDetailPage`.

| المنطقة | السلوك | القيد |
| --- | --- | --- |
| الهوية | `h1` هو مرجع العملية، ثم اسم العميل، ثم لقطة الاسم | `data-dossier="loaded"` بعد وصول البيانات |
| الإجراء التالي | نص `next_action` من الخادم، ظاهر قبل الأقسام | لا زر يختلق إجراء |
| المساران | `DualLane`: مستندات حسب BANK أو DIRECT، وبضاعة من حالة الحاويات. الوصول للميناء ليس تسليمًا | الخطوات من الحالات الحقيقية |
| الأقسام | الفاتورة، المستندات، البنك، البريد، الحجز، التذكير، المشاركة | نفس اللوحات ونفس واجهات API |
| الفاتورة المقفلة | شارة وقفل عند `COMPLETED`. التصحيح يظهر فقط مع `invoices.correct_completed` | لم يتغير حساب الإجمالي |
| البنك | مسار DIRECT يعرض نصًا أن مراحل البنك لا تُفرض | الكود السابق بقي |
| الحاويات | اللوحة السابقة. لم يُختلق رقم ISO | عرض الخانات يعتمد البيانات القادمة من API |

لم تُبنَ أربع تركيبات جديدة للتصوير في هذه النقطة. اختبارات E2E القائمة تنشئ عمليات بنك ومباشر وقفل فاتورة أثناء التشغيل.
