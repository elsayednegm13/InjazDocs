# التعريب والأخطاء — Checkpoint 06

أُضيفت مفاتيح عربية وإنجليزية لـ `INVOICE_LOCKED` وسبب التصحيح وحالة القفل والتصحيح الاستثنائي و«مرة واحدة» وفاصل التكرار. اختبار القواميس يفرض تطابق المفاتيح.

الرسالة العربية للقفل: «هذه الفاتورة مقفلة بعد اكتمال عملية التصدير. يلزم تصريح تصحيح خاص.»

لم تُراجع كل الجمل القديمة في هذه الجولة. المعرّفات تبقى داخل `Ltr`. لا SQL في جسم خطأ القفل حسب اختبار E2E.
