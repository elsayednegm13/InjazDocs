# سلامة تصحيح الفاتورة — الخيار ج

الحالة: مُختبرة على قاعدة E2E المعزولة فقط. هذه الجولة لم تنفّذ `db:migrate:local` ولم تلمس `.wrangler/state` بأمر ترحيل.

## العقد

تصحيح استثنائي ناجح عملية واحدة عبر `D1Database.batch()` بالترتيب:

1. `UPDATE export_invoices ... WHERE id = ? AND version = ?`
2. `INSERT INTO invoice_revisions ... SELECT ... WHERE changes() = 1`
3. عبارات الحقول الإضافية مشروطة بـ `(SELECT version FROM export_invoices WHERE id = ?) = nextVersion`
4. في الاختبار فقط، وعند `EXPORTFLOW_TEST_FAULTS=1` و`testFault=constraint`: إدراج مراجعة بمفتاح أجنبي غير موجود
5. إدراج `audit_log` مشروط بالإصدار الجديد

إذا لم يغيّر التحديث أي صف، تُرمى `409 INVOICE_VERSION` ولا يُحذف صف وهمي، لأن إدراج المراجعة مشروط بـ `changes() = 1`. فشل أي عبارة لاحقة (مثل المفتاح الأجنبي) يُلغي الدفعة كلها حسب سلوك D1. الكتابة العادية للفاتورة وللحقول الإضافية بعد اكتمال العملية تبقى `409 INVOICE_LOCKED`.

`changes() = 0` داخل الدفعة لا يُفشل الدفعة. لذلك لا يُعتمد على فشل التحديث وحده للتراجع؛ العبارات التالية لا تكتب إلا إذا أصبح الإصدار هو الإصدار المتوقع.

## ما أُثبت

- إعادة تشغيل SQL على نسخة من قاعدة E2E باستخدام `node:sqlite`: التحديث ثم المراجعة ثم الحقل ثم التدقيق ينجح، والنسخة القديمة تُدرج صفر صفوف، وخطأ المفتاح الأجنبي يتراجع ويُبقي الإصدار والمجموع.
- `e2e/invoice-lock.spec.ts` على `.wrangler-e2e` فقط، الأمر `corepack pnpm exec playwright test e2e/invoice-lock.spec.ts --reporter=list`، انتهى `2026-10-14T20:25:23Z`، **4 passed**، خروج **0**، نحو 55 ثانية. يشمل: قفل الكتابة العادية، سبب فارغ بلا مراجعة، رفض مدير العمليات 403، رفض حقول إضافية 409، تصحيح يجمع المجموع مع حقل نصي، سباق نسختين (واحد 200 وواحد 409 ومراجعتان)، وحقن قيد يفشل مع بقاء المجموع والإصدار والحقل وعدد المراجعات.
- سجل العامل في تشغيل سابق ناجح (`20:20Z`): `correction:applied 1` ثم `1` ثم `0` ثم `D1_ERROR: FOREIGN KEY constraint failed`. التأكيدات بقيت ناجحة، أي أن الفشل لم يُبقِ كتابة جزئية.
- عندما أعاد وكيل Vite صفحة HTML فيها `fetch failed` قبل وصول المعالج، بقيت الفاتورة عند الإصدار 2 وبلا صفوف في `invoice_revisions`. لا التزام جزئي في تلك المحاولات.

## ما لم يُثبت

- لم تُشغَّل الدفعة على قاعدة المطوّر في هذه الجولة.
- وجود الجدول على قاعدة المطوّر (انظر وثيقة الموافقة) لا يعني أن هذا المسار اُختُبر عليها.
- تزامن أكثر من عميلين خارج اختبار Playwright المعزول لم يُعد تشغيله على خادم إنتاج.
