# قرارات التصميم — Checkpoint 06.6.1

بقيت هوية الحبر `#10283F` والورق `#F7F8F6` والزر `#0C5C56`. لم يُفتح اتجاه جديد منافس لأن 06.6 اختار بالفعل رأس الملف والمسارين، وهذه النقطة تكمل الخانات والالتفاف.

المرفوض: لوحة أرقام، سفن زخرفية، نحاس للنص (2.81)، Tailwind Plus، shadcn، خط مستضاف بلا قياس حمولة في هذه الجولة.

المضاف بعد لقطات «قبل»: قائمة خانات ظاهرة دائمًا، وخطوات المسار في شبكة عمودين تحت عرض `sm` حتى لا تُسحق التسمية في سطر واحد.
